# v0.3.0 (2026-03-30)

## バグ修正

- **macOS CPU 使用率が常に 0% になる問題を修正**
  - Mach API (`host_processor_info`) を直接呼び出して実際の CPU ティック数を取得するよう変更
  - 旧実装は `sysinfo::global_cpu_usage()` を単一リフレッシュで呼び出していたため常に 0 を返していた

## 新機能

### フォーマット拡張

- **`{}` 内にリテラル文字列を埋め込み可能に**
  - 構文: `{"prefix"key:.1"suffix"}` — キーが N/A のときプレフィックス・サフィックスも含めて非表示になる
  - GPU 非搭載環境でのテンプレートをクリーンに記述できる
  - 例: `{cpu:.1}%  {mem_used:.1}/{mem_total:.1}G{"  "gpu_name}{" "gpu_util:.1"%"}`

- **N/A を空文字列で表示**
  - GPU 非対応キーを `N/A` ではなく空文字列としてレンダリング

### GPU

- **`--debug` オプションを追加**
  - 各メトリクスの取得状況・エラー内容・キャッシュ状態を stderr に出力

- **NVIDIA GB10（Grace Blackwell）のメモリ情報に対応**
  - unified memory アーキテクチャで `nvmlDeviceGetMemoryInfo` が `NotSupported` を返す場合、ホストのシステムメモリにフォールバック

- **古い NVIDIA ドライバへの対応改善**
  - `nvmlDeviceGetMemoryInfo_v2` シンボルが存在しない場合、v1 API へ自動フォールバック

- **`{cuda_ver}` プレースホルダーをヘルプに追記**
