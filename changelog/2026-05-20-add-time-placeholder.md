# 2026-05-20 情報取得時刻プレースホルダーの追加

## 概要

情報取得時刻をステータスラインに表示できるよう、`{time}` プレースホルダーを追加した。

## 変更点

- `{time}` プレースホルダーを追加。ローカルタイムゾーンで `HH:MM:SS` 形式（例: `14:23:05`）を表示する。
- 時刻取得は新規モジュール `src/clock.rs` に実装。依存クレートは追加せず、`localtime_r`（libc）の FFI でローカル時刻へ変換する（macOS / Linux 両対応）。
- `parse_needed` に `time` フラグを追加し、フォーマットに `{time}` が含まれる場合のみ取得する。
- ヘルプ・README のプレースホルダー一覧を更新。

## 使用例

```bash
simple-stats --format "{cpu}% | {time}"
# => 23% | 14:23:05
```
